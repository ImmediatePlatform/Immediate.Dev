The .NET Aspire sample composes an ASP.NET Core jobs API with PostgreSQL and the Aspire dashboard.
It demonstrates durable EF Core storage, health checks, telemetry, recurring work, request-context
capture, fair queues, and multi-step batch workflows alongside the Immediate.Jobs dashboard.
